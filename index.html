The synth I'm building

I started this in late September and I'm aiming to have it working in about six weeks. It's a 4-voice synth that I can play from my own keyboard.

The plan is to split it up the way a lot of real synths are built. An STM32 reads the MIDI notes coming in from the keyboard and the knob positions, then sends the settings to an FPGA over SPI. The FPGA makes the actual sound in Verilog: four oscillators, an envelope on each one (attack, decay, sustain, release), and a lowpass filter. The audio goes out over I2S to a DAC and then to a speaker.

Parts: STM32 Nucleo-F446RE, Tang Nano 20K FPGA board, PCM5102A DAC.

Where it's at: still building. I'll put the code and a demo video here once it actually makes sound.

Play it

This is a browser version of the same idea, so you can hear what I'm going for. Each voice has a counter that adds a fixed number every sample, and the size of that number sets the pitch (that's how the oscillators on the FPGA are going to work too). Then the envelope shapes how loud the note is over time.

8051 trainer kit

In my high school electronics lab we programmed an 8051 trainer kit by typing hex opcodes straight into memory, running them, and checking the results in binary. This is a small version of that kit. The program that's loaded multiplies 3 by 5 by adding 3 five times, since the loop is easier to follow than the MUL instruction.

    Only handles some instructions: MOV, ADD, ADDC, SUBB, INC, DEC, ANL, ORL, XRL, RL, RR, CLR, CPL, SJMP, JZ, JNZ, DJNZ, NOP.
